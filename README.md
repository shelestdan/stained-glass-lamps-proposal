# КП для интернет-магазина витражных светильников

Статическая HTML/CSS/JS-страница коммерческого предложения в стиле темной премиальной презентации. Сборка не нужна.

## Как открыть

Откройте `index.html` в браузере.

Локальный сервер:

```bash
python3 -m http.server 8080
```

Потом открыть `http://localhost:8080`.

## Что внутри

- `index.html` — структура КП.
- `styles.css` — весь визуал, адаптивность, темная grid-презентация.
- `script.js` — плавный скролл, reveal-анимации, активная навигация.
- `assets/` — favicon, OG SVG и сгенерированные изображения для hero, аудиторий, карточки товара и витражной фактуры.
- `robots.txt`, `sitemap.xml` — нейтральные базовые файлы.

## Фиксированная цена

В КП указана стоимость `70 000 ₽`.

## Перед отправкой клиенту

Проверьте:

- состав работ за 70 000 ₽;
- сроки;
- реальные условия оплаты и доставки;
- точный тариф reg.ru;
- нужен ли backend, оплата, админка и интеграции на первом этапе;
- заменить `https://example.com/` в `sitemap.xml`, если КП публикуется на домене.

Контакты не указаны: клиент уже знает исполнителя.

## Публикация на reg.ru

Загрузить в корень хостинга:

- `index.html`
- `styles.css`
- `script.js`
- `robots.txt`
- `sitemap.xml`
- папку `assets/`

Для КП в `index.html` стоит `noindex, nofollow`, чтобы предложение случайно не индексировалось.
